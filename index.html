Setup Guide — 10 minutes, free

      
    
        
  1. Create a Google Sheet
    Go to sheets.new — name it “Livom Quiz Results”.
    2. 
        
  2. Open Apps Script
    In the Sheet: Extensions → Apps Script. Delete existing code, paste the script below.
    3. 
        
  3. 
          Paste this script:
          
    function doGet(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSheet();
    var data  = JSON.parse(decodeURIComponent(e.parameter.data));
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(data.headers);
      sheet.getRange(1,1,1,data.headers.length)
           .setBackground('#1A1612')
           .setFontColor('#C9A85C')
           .setFontWeight('bold');
    }
    sheet.appendRow(data.row);
    return ContentService
      .createTextOutput(JSON.stringify({status:'ok'}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({status:'error',msg:String(err)}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
    
        
    4. 
        
  4. Deploy as Web App
    Click Deploy → New deployment. Type: Web app. Execute as: Me. Who has access: Anyone. Click Deploy → copy the URL.
    5. 
        
  5. 
          Paste the URL into this HTML file
    
          Open the file in a text editor. Find this line and replace the placeholder:
    
          const GOOGLE_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycbyejddsO6MgvUudFsEs5-3La1fA_gf5ngYUWg02RnuQYUb2xaSdPxJcVkoqGTrV7YT5zw/exec';
          Replace with your URL, e.g. https://script.google.com/macros/s/ABC.../exec
        
    6. 
      

      

        ✓ Once connected: Every time a showroom manager finishes the quiz on any device, their results appear instantly in your Google Sheet. Share the HTML file via email, Google Drive, or WeTransfer.
